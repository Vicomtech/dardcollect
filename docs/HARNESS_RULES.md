# Harness Rules Archive

Adopted harness rules keyed by the failure or incident that motivated them (pattern recycled from
the ai-harness-eng rule archive, 2026-09-09). When a session turns a lesson
into a rule, add the row here in the same cycle. A rule whose motivating failure no longer applies
is a retirement candidate, not automatic deletion.

Enforcement states which deterministic artifact fails on violation
(`validate_harness.py`, `quality_gates.py`, `privacy_scan.py`, `license_scan.py`,
`objective_gate.py`, `pre-commit hook`, `regression tests`), or `advisory` when only prose
enforces it. Vocabulary fixed in `scripts/harness_extra.py`; check `rule enforcement` fails on
any other value, so a gated rule whose gate was deleted is visible instead of silently advisory.

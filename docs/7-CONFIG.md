# Configuration reference

All stages read one YAML file. The shipped configs are in [`configs/`](../configs/):

| File | Use |
|---|---|
| `config.archive_all.yaml` | Full Archive.org run (default). |
| `config.test.yaml` | Fixture run; generated by `scripts/make_test_config.py`. |
| `config.seed.yaml` | Minimal download to seed a fixture. |
| `config.custom_*.yaml` | Examples for custom datasets (`videos`, `images`, `audios`, `texts`, `ravdessfake`). |

## How a config is chosen

- `scripts/run_pipeline.py --config <file>` runs all stages with that file.
- Stage scripts run alone read `configs/config.archive_all.yaml`. Set the
  `DARDCOLLECT_CONFIG` environment variable to use another file.
- Paths are relative to the repository root.

## Path templates

Any top-level scalar key can be substituted into `{key}` placeholders anywhere in
the file. The archive config uses `root`; custom configs typically use `output_root`:

```yaml
root: "/data/DARD"
person_extraction:
  input_dir: "{root}/archive_org_public_domain/videos"
  output_clips_dir: "{root}/extracted_person_clips"
```

Change `root` once to relocate every path. An individual section can still
override a path with a literal value. Keep `base_output_dir` equal to
`{root}/archive_org_public_domain` in the archive config, because the download
stage reads it separately.

## Top-level keys

| Key | Default in shipped config | Meaning |
|---|---|---|
| `media_types` | `[video, image, audio, text]` | Modalities to download. |
| `root` | — | Base for `{root}` templates. |
| `base_output_dir` | — | Download destination; must equal `{root}/archive_org_public_domain`. |
| `search_sort` | `date desc` | Archive.org result order. |
| `max_workers` | `10` | Parallel download threads. |
| `max_total_size_gb` | `2` | Stop downloading when this total is reached. |
| `retry_delay` | `5` | Seconds before retrying a failed download. |
| `gpu_id` | `0` | GPU index. |
| `log_level` | `INFO` | Log verbosity. |

### `download`, `encoding`, `run_pipeline`

| Key | Shipped | Meaning |
|---|---|---|
| `download.av1_policy` | `warn` | `warn` logs AV1 sources; `skip` deletes them and records the skip in `downloads.csv`. |
| `encoding.video_codec` | `libx264` | Video encoder. Hardware encoders need a system ffmpeg. |
| `encoding.audio_codec` | `aac` | Audio encoder. |
| `encoding.encoder_threads` | `8` | Encoder threads. |
| `run_pipeline.skip_download` | `false` | `true` for an existing dataset. |
| `run_pipeline.skip_stages` | — | Stage aliases to skip; dependent stages are skipped too. |
| `run_pipeline.heartbeat_interval_seconds` | `10` | Status update interval. |
| `run_pipeline.rerun_interval_seconds` | `20` | Wait before relaunching a downstream stage. |

### `media_download`

Per modality (`video`, `image`, `audio`, `text`): `output_subdir` (relative to
`base_output_dir`), `search_query` (Archive.org query) and, for video,
`min_duration_minutes` (default `20`).

## Stage sections

Each section belongs to one stage. The stage order is in
[0-GETTING-STARTED.md](0-GETTING-STARTED.md#stages).

### `person_extraction` — `extract_person_clips_from_videos.py`

| Key | Shipped | Meaning |
|---|---|---|
| `input_dir`, `output_clips_dir` | — | Input videos; output clips. |
| `min_free_disk_gb` | `2.0` | Abort before writing below this free space. |
| `detection_threshold` | `0.4` | Minimum person-detection confidence. |
| `max_bbox_area_percent`, `max_detection_aspect_ratio` | `60.0`, `2.0` | Reject oversized or elongated boxes. |
| `tracking_score_threshold`, `tracking_min_hits`, `tracking_max_time_lost` | `0.4`, `3`, `10` | Tracker association and lifetime, in frames. |
| `pose_keypoint_threshold` | `0.4` | Minimum keypoint confidence. |
| `require_face_visibility`, `min_face_size_percent`, `min_face_visible_frames`, `min_consecutive_face_frames` | `true`, `10.0`, `15`, `5` | Face requirements for a clip. |
| `require_frontal_face`, `frontal_symmetry_threshold` | `true`, `0.65` | Frontal-face filter (0 = any yaw, 1 = perfectly frontal). |
| `enable_visual_speaking` | `true` | Count frames with an open mouth. |

| `scene_change_block_delta*` | `false`, `24.0`, `0.5` | Optional third cut signal, off by default. |

| `min_consecutive_frames`, `merge_gap_frames` | `10`, `10` | Minimum run length; gap merging. |

### `image_extraction` — `extract_persons_from_images.py`

`input_dir`, `output_detections_dir`, `overwrite` (`true`); the detection and
face filters mirror `person_extraction` (`detection_threshold: 0.4`,
`min_face_size_percent: 10.0`, `frontal_symmetry_threshold: 0.65`).

### `face_crop_extraction` — `extract_face_crops_from_videos.py`

| Key | Shipped | Meaning |
|---|---|---|
| `input_dir`, `output_dir` | — | Clips; crops. |
| `include_audio` | `true` | Mux the clip's audio into each crop video. |
| `detection_threshold`, `pose_keypoint_threshold` | `0.3`, `0.3` | Lower than person extraction on purpose. |
| `min_eye_distance_px` | `10` | Minimum inter-eye distance. |
| `min_track_face_frames` | `10` | Tracks with fewer valid frames produce no crop. |
| `skip_no_face_frames` | `false` | `true` drops frames with no face instead of keeping them. |
| `max_overlap_iou` | `0.3` | Overlap threshold between tracks. |
| `stabilize_face_crops` | `true` | Fit pose from dense CIGPose eye contours; smooth pose and compute the smoothest eye-midpoint path within the configured alignment tolerance. Design: [DESIGN_landmark_stabilization.md](DESIGN_landmark_stabilization.md). |
| `stabilization_min_frames` | `5` | Minimum track length for stabilization. |
| `stabilization_window_seconds` | `0.8` | Zero-phase Savitzky–Golay window for crop angle and log-scale. Multi-video trials showed lower jitter; `stabilization_anchor_tolerance_px` bounds eye-center drift. |
| `stabilization_anchor_tolerance_px` | `2.5` | Maximum eye-midpoint deviation from the canonical anchor, measured in 616×616 output pixels. The smoother minimizes crop acceleration within this bound. |
| `stabilization_eye_min_confidence` | `0.2` | A CIGPose eye-contour landmark below this confidence is not counted as evidence. |
| `stabilization_eye_min_landmarks` | `3` | Contour landmarks each eye needs per frame for that frame to count as an eye observation. |

Changing stabilization settings requires deleting the existing crop videos and
sidecars, not only the `.done` sentinels, before re-rendering.

#### How the stabilization parameters combine

- `stabilization_window_seconds` becomes an odd number of frames (`fps × seconds`;
  a window under 3 frames means no smoothing). The longer the window, the smoother
  the pose, but the slower it follows real head motion.
- `stabilization_anchor_tolerance_px` is the budget the eye-midpoint path may drift
  from the detected eyes. The solver minimizes crop acceleration inside that budget.
- `stabilization_eye_min_confidence` and `stabilization_eye_min_landmarks` decide
  which frames count as observations. Lowering them keeps more frames of a difficult
  track; raising them trusts only clearly visible eyes.
- `stabilization_min_frames` is the evidence a track needs before it is stabilized at
  all. Below it, the track keeps its per-frame OFIQ alignment (nothing is dropped).

#### Fixed in code, not configurable

These stay constant by design (documented in
[DESIGN_landmark_stabilization.md](DESIGN_landmark_stabilization.md)); the window is
the intended knob for smoothness.

| Constant | Value | Why |
|---|---|---|
| Savitzky–Golay passes | 2 | A cascade cuts jitter at the same window; the window stays the knob. |
| Anchor-relaxation ladder | 1×→2×→4×→8×→16× | Only engages when the solver cannot honour the budget; each relaxation is logged. |
| Solver iteration limit | 10 000 | Raised from 1 000 after 80 of 4 904 RAVDESSfake clips failed to converge. |
| Eye-contour landmark groups | indices 59–64 and 65–70 | The two six-point CIGPose eye contours. |
| Canonical interocular distance | 113 px on the 616 canvas | OFIQ alignment target, from `face_geometry.py`. |

## Defaults and required keys

Behaviour keys that are omitted fall back to the default in
[`dardcollect/config.py`](../dardcollect/config.py). These defaults match the shipped
values, so a config that leaves a key out behaves as the shipped config does.

Keys that have no default must be set, and the stage stops with
`Missing required config key: <section>.<key>` when they are absent. They include
the input and output directories of the stages that read them, the quality threshold of
the face quality filters, and most `person_extraction` thresholds.
`image_face_crop_extraction.detections_dir` is required too: the image crop stage
reads the detection JSONs from it.

Three kinds of key still differ from the shipped file, on purpose:

| Key | Shipped | Code default | Why |
|---|---|---|---|
| `image_extraction.overwrite` | `true` | `false` | Omitting it never recomputes existing detections. |
| `face_quality_annotation.overwrite` | `true` | `false` | Same. |
| `image_face_quality_annotation.overwrite` | `true` | `false` | Same. |

Path defaults (`DARD/...`) are relative fallbacks for runs without a config; the
shipped configs always set them with `{root}`.
